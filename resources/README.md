# Kommanda — The Workflow-First File Manager for macOS

Kommanda isn't just about managing files; it's about navigating, previewing, editing, and understanding them. It transforms the passive act of file management into an active, intelligent workflow.

## 🚀 Key Features

### precision Navigation
- **Dual-Pane Layout**: The classic, efficient way to move and copy files (F5/F6) without the window clutter.
- **Smart Path Bar**: Jump to any parent directory instantly with expandable path chevrons.
- **Advanced Search**: Filter files using standard wildcards (`*.png`) or full **Regular Expressions** for precision finding.
- **Terminal Integration**: Open the current folder in your Terminal with a single click.

### Integrated Preview & Editing
Why switch apps just to make a small change?
- **Markdown**: Edit freely and switch to a fully rendered preview mode instantly.
- **PDFs**: Annotate, highlight, and add notes directly within the app.
- **Code & Text**: Lightweight syntax highlighting and inline editing.

### 🤖 AI Assistant (Local & Cloud)
Interact with your files using natural language.
- **Intelligent Agent (v1.7.0)**: Ask "Create a website" or "Merge these PDFs" and Kommanda will plan and execute the necessary file operations automatically.
- **Tool-Equipped**: The AI has "hands" on your files—it can create, move, rename, delete, and process documents (PDF/Text) directly.
- **Context-Aware**: The agent understands the dual-pane state, allowing for commands like "Copy the images from the left pane to a new folder on the right."
- **Deep Search**: Find files by intent ("invoice from last week") or structure ("folders containing audio") using the built-in `FindFilesTool`.
- **Privacy Choice**:
    - **Ollama**: Run AI locally on your device for maximum privacy.
    - **Google Gemini**: Connect to the cloud for advanced reasoning and massive context windows.
    - **OpenAI**: Full support for GPT-4o and GPT-4o-mini models.

#### Why Kommanda AI?
Unlike standalone AI chats, Kommanda's agent has **"eyes" on your file system**. It bridges the gap between raw file management and natural language intent, automating the "grunt work" of scaffolding, organizing, and analyzing your data without you needing to leave the app.

### 🛡️ System Hardening
- **Safe Previews**: Robust video playback system that handles corrupt or missing files without crashing.
- **Fluid UI (v1.7.0)**: Interactive hover scaling makes files "lift" as you browse, and spring-animated transitions provide a tactile, responsive feel.
- **Auto-Healing Paths**: File operations intelligently manage directory structures to prevent "not found" errors.
- **Snappy Grid**: High-performance thumbnail navigation with zero-flicker selection and accurate arrow-key tracking.

### "Swiss Army Knife" Utilities
- **PDF Merger**: Combine multiple PDF documents into one.
- **Image Tools**: Crop and overlay images quickly.
- **Archive Management**: Compress and organize directly.
- **Bookmarks**: Save your most-used locations for one-click access.

### Customization
- **Themes**: Choose from System, Light, Dark, or the nostalgic **Norton** blue theme.
- **Layouts**: Toggle between list views, thumbnails, or tree structures.

## Getting Started

1.  **Launch Kommanda**: You'll see the dual-pane interface.
2.  **Grant Access**: Click the lock icon to give Kommanda access to your Home folder (required for macOS sandboxing).
3.  **Start Working**: Use **Space** to Quick Look, **F5** to Copy, and the **AI Button** to start chatting.

## Shortcuts at a Glance
- `F5` / `F6`: Copy / Move
- `F7`: New Folder
- `F8`: Delete
- `Cmd+P`: Toggle Preview Panel
- `Cmd+T`: Open in Terminal
